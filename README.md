# 🛒 MyStore - E-Commerce
A lightweight, modern, and fully responsive *3-page e-commerce website* built purely using *Vanilla HTML5, CSS3, and JavaScript (ES6+)*. This project features real-time cart management, dynamic product searching/filtering, cart, and an intuitive order checkout.
---
## 🌟 Features
- 📱 *Fully Responsive Layout*: Seamless user experience across desktops, tablets, and mobile devices using CSS Grid and Flexbox.
- 🛍️ *3 Core Pages*:
  - *Home (index.html)*: Hero banner, store highlights/features, and handpicked featured products.
  - *Products Catalog (products.html): Live search bar, category filtering (*Electronics, Fashion & Bags, Accessories), and product cards with rating badges.
  - *Shopping Cart & Checkout (cart.html)*: Interactive cart table with quantity modification, line item removal, subtotal & shipping calculation, and modal checkout form.
- 💾 *Local Storage Persistence*: Cart state automatically syncs across all pages and persists across browser refreshes.
- 🔔 *Toast Notifications*: Interactive toast alerts when products are added or removed from the cart.
- ⚡ *Zero External Framework Dependencies*: Pure HTML, CSS, and JS — no React, Vue, jQuery, or heavy bundle setups required.
